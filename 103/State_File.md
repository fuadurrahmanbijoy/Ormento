# State File

*One compact file for every drafting chat: settled choices, blueprint entries, term bank, case file. Append only the 'New' items from each chapter's ending (Part V, section 5); never reprint. No course-file material appears here.*

## 0. Settled choices and chosen words

- **Spelling and dates:** British spelling; dates as day, month, year (12 March 2026).
- **Country and money:** Bangladesh; taka written *Tk 158,000*; international digit grouping (to confirm, see Blueprint B.2). Bangladesh law and the accounting standards in force there apply; other systems noted only where they differ.
- **Running business:** Mitali Bakery (illustrative), a sole trader, shown as a documented case file with the opening line *Case file, illustrative.*
- **Chosen words (one term, one word):** *income statement* (also called profit and loss account); *balance sheet* (statement of financial position); *owner's equity* for a sole trader, *partners' capital* for a partnership, *shareholders' equity* for a company; *inventory* (not stock); *worksheet*; *on account*; *revenue* in general and *sales* for merchandise from Chapter 13; *profit*; *drawings*; *accounts receivable* and *accounts payable*; *journalise*; *cheque*; *plant asset* in Chapter 10, *non-current asset* from Chapter 13; *liquidation*; *share*; *par value*.
- **Word in use notes** (at most three a chapter) are marked in the term bank by the word to annotate.
- **Avoid:** simply, just, obviously, clearly, of course; idioms and phrasal verbs.
